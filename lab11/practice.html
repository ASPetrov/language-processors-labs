Задачи

Построй таблиците и обоснови коя проверка е необходима.

1. Декларации и видимост

program {

    int level = 2;

    twice(int value) -> int {
        int result = value + value;
        return result;
    }

    main() -> void {
        int level = 7;
        print(@twice(level));
    }
}

Запиши имената, видовете и типовете в трите таблици. Коя level се използва при извикването? Видима ли е result в main?

  • Глобална: level: int, twice: (int) → int, main: () → void.
  • twice: параметър value: int и локална result: int.
  • main: локална level: int; тя се използва за аргумента.

result не се вижда от main. Двете функции имат отделни локални таблици с общ глобален родител.

2. Разпознай грешката

Разгледай фрагментите независимо, всеки в тялото на main. Определи защо не минават семантичните проверки.

int count = true;
int total = 4;
int total = 9;
print(missing);
  1. Несъвместими типове: на int се присвоява boolean.
  2. Две декларации на total в един и същ блок.
  3. Няма достъпна декларация на missing.
