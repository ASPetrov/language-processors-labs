Лабораторно 11

Кое име вижда анализаторът?

Една програма, три таблици и две различни декларации на score.

program {

    int score = 40;
    int bonus = 3;

    add(int left, int right) -> int {
        return left + right;
    }

    main() -> void {
        int score = 6;
        print(@add(score, bonus));
    }
}

Йерархия на символните таблици

Глобалната таблица е общият родител. Таблиците на add и main са на едно ниво; при търсене преминаваме към родителя, а не към съседната функция.

  • Глобален блок

    Име Вид Тип / параметри
    score Променлива int
    bonus Променлива int
    add Функция (int, int) → int
    main Функция () → void

    • Функция add

      Име Вид Тип
      left Параметър int
      right Параметър int

      Обхващащ блок: глобалният.

    • Функция main

      Име Вид Тип
      score Локална променлива int

      Обхващащ блок: глобалният.

Проследи търсенето

В main името score се намира локално и припокрива глобалното. За bonus търсенето продължава към глобалната таблица.

Търсенето от add преминава към глобалния блок, а не към локалната таблица на извикващата функция main.

Кои декларации се използват за аргументите в @add(score, bonus)?

Обяснение

Първо търсим в main. Имената на формалните параметри принадлежат на таблицата на add.

Ако добавим print(left); в main, какво ще стане?

Обяснение

left е параметър на add. Той не се вижда от main и няма глобална декларация с това име.
