Лабораторно 1

Домашно и самопроверка

Домашното проверява дали разбираш архитектурата, а не дали си запомнил определения.

Домашна работа — „Анализирай програмата като компилатор“

program {
    int x = 5;
    main() -> void {
        int y = 10;
        print(x + y);
    }
}
  1. Начертай пътя на програмата през модулите на учебния компилатор.
  2. За всеки модул напиши с едно изречение какво получава и какво произвежда или проверява.
  3. Обясни каква е ролята на лексическия, синтактичния и семантичния анализатор.
  4. Обясни с по едно изречение разликата между свързващ редактор и зареждаща програма.
  5. Обясни защо учебният компилатор използва интерпретатор за виртуална машина.

Самопроверка

1. Кой модул преобразува поток от символи в поток от лексеми?
Лексическият анализатор.
2. Кой модул формира абстрактно синтактично дърво?
Синтактичният анализатор.
3. Къде се проверяват областите на видимост и съвместимостта на типовете?
В семантичния анализатор.
4. Кой зарежда транслираната програма в оперативната памет?
Зареждащата програма.
5. Кои са входният и инструменталният език на учебния компилатор?
Входният език е STUDENT, а инструменталният език е Java.
За следващото упражнение: формални граматики, езици и правилата, чрез които описваме синтаксиса.
