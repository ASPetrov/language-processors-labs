Упражнение 8

Примери: от правило към функция

Примери

При всеки: правило → какво означава → Java функция → проследяване → кратка проверка. Схематичните имена a, b и т.н. обозначават терминали.

1. Последователност

Граматика → алгоритъм → код

A : abB

Терминалите се приемат последователно; после се извиква функцията за нетерминала.

void A() {
    accept(a);
    accept(b);
    B();
}

2. Незадължителна част (?)

Граматика → алгоритъм → код

A : a(bB)?

Знакът ? означава нула или едно изпълнение: затова използваме if.

void A() {
    accept(a);
    if (currentToken == b) {
        accept(b);
        B();
    }
}

3. Повторение (*)

Граматика → алгоритъм → код

A : a(bB)*

Знакът * допуска нула или повече повторения: затова използваме while.

void A() {
    accept(a);
    while (currentToken == b) {
        accept(b);
        B();
    }
}

4. Две алтернативи

Граматика → алгоритъм → код

A : abB | cC

Изборът е по FIRST на двата клона. Тук добавяме явна проверка за невалиден терминал, вместо неограничен else.

void A() {
    if (currentToken == a) {
        accept(a);
        accept(b);
        B();
    } else if (currentToken == c) {
        accept(c);
        C();
    } else {
        throw new SyntaxException(...);
    }
}

5. Множество алтернативи

Граматика → алгоритъм → код

A : abB | d(aA)* | e(eE)?

switch избира по началния терминал. Извикването A() е рекурсивно, но се извършва след прочитане на a.

void A() {
    switch (currentToken) {
        case a:
            accept(a); accept(b); B();
            break;
        case d:
            accept(d);
            while (currentToken == a) {
                accept(a); A();
            }
            break;
        case e:
            accept(e);
            if (currentToken == e) {
                accept(e); E();
            }
            break;
        default:
            throw new SyntaxException(...);
    }
}

Коя конструкция реализира (bB)*?

Обяснение

* допуска произволен брой повторения, включително нула.

Какво е важно при if/else за алтернативи?

Обяснение

LL(1) изисква избор само по една лексема напред.
