Практически задачи

Задача 1

Да се съставят синтактични функции за разпознаване на нетерминалния символ B чрез рекурсивно спускане. Главните букви означават нетерминали, малките — терминали.

Работа в час: напиши всяка функция самостоятелно. При нужда отвори подсказката, а решението — след собствен опит. Полето за код е за упражнения и не изпълнява Java; не се прави автоматична оценка на свободния код.

Последователност от терминали и нетерминал.

Условие от ръководството

B : cdE
Подсказка

Първо обработи двата терминала, после извикай нетерминала E.

void B() {
    accept(c);
    accept(d);
    E();
}

Защо? Последователност от терминали и нетерминал. Проверявай текущия терминал и не приемай непознат клон за валиден.

Повторение нула или повече пъти.

Условие от ръководството

B : b(bC)*
Подсказка

След първото b използвай цикъл за повтарящата се част.

void B() {
    accept(b);
    while (currentToken == b) {
        accept(b);
        C();
    }
}

Защо? Повторение нула или повече пъти. Проверявай текущия терминал и не приемай непознат клон за валиден.

Незадължителна част и рекурсивно извикване.

Условие от ръководството

B : b(cB)?
Подсказка

След b проверявай дали незадължителната част започва с c.

void B() {
    accept(b);
    if (currentToken == c) {
        accept(c);
        B();
    }
}

Защо? Незадължителна част и рекурсивно извикване. Проверявай текущия терминал и не приемай непознат клон за валиден.

Три алтернативи и повторение.

Условие от ръководството

B : bB | cC | d(aC)*
Подсказка

Избери клон според b, c или d. При d има и цикъл.

void B() {
    switch (currentToken) {
        case b: accept(b); B(); break;
        case c: accept(c); C(); break;
        case d:
            accept(d);
            while (currentToken == a) {
                accept(a);
                C();
            }
            break;
        default: throw new SyntaxException(...);
    }
}

Защо? Три алтернативи и повторение. Проверявай текущия терминал и не приемай непознат клон за валиден.
