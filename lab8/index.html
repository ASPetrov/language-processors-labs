Какво ще можеш след упражнението?

Да разпознаваш граматични конструкции, да определяш кой клон се избира по текущата лексема и да превръщаш правила в синтактични функции на Java.

Граматика → Избор по лексема → Java функция → Разпознаване

Първа среща с рекурсивното спускане

A : abB
void A() {
    accept(a);
    accept(b);
    B();
}

accept(a) проверява терминал a, а B() разпознава нетерминала B. Това е схематичен учебен Java код, не директно компилируем клас.

Как ще работим?

Първо наблюдавай как анализаторът взема решение; след това проследи изпълнението; накрая напиши самостоятелно четирите функции от ръководството. Решенията са скрити.
