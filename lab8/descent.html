Упражнение 8

Рекурсивно спускане

Всяка синтактична функция разпознава един нетерминал.

Три правила за превод

Терминал → accept(…) · Нетерминал → извикване на функция · Алтернатива → избор по текущата лексема.

Проследи изпълнението

A : abB
void A() {
    accept(a);
    accept(b);
    B();
}

За демонстрацията приемаме B : c и вход abc. Това допълнение служи само за проследяване.

Синтактично дърво

При низходящ анализ започваме от корена и разгръщаме нетерминалите. Схематичното дърво по-долу съответства на демонстрационната граматика A : abB; B : c.

Какво прави accept()?

void accept(TokenType expected) {
    if (currentToken.getTokenType() != expected) {
        throw new SyntaxException(...);
    }
    currentToken = lexer.nextToken();
}

Защо лявата рекурсия е проблем?

A : Ab

Наивна реализация би извикала A() отново, преди да е прочела терминал. Това води до неограничена рекурсия.
