Лабораторно 7

Същност на синтактичния анализ

Как парсерът разпознава синтактично правилни програми.

Вход, проверка и резултат

Синтактичният анализатор получава поток от лексеми от лексическия анализатор. Проверява дали те образуват валидно изречение според граматиката на езика и изгражда синтактично дърво.

Поток от лексеми→Парсер→Синтактично дърво

Примери за синтактични грешки

1. Незатворени скоби

program {
    main() -> void {
        print("Hello");
    }
// Липсва затварящата скоба на program

Отварящата скоба { на програмата няма съответстваща затваряща скоба }. Правилото program : PROGRAM LBRACKET program_body RBRACKET изисква RBRACKET.

2. Липсваща точка и запетая

program {
    main() -> void {
        print("Hello")
    }
}

Според statement : simple_statement SEMICOLON | compound_statement простият оператор трябва да завършва с SEMICOLON.

3. Невалиден оператор

program {
    main() -> void {
        int a;
        a = 5 + ;
    }
}

След оператора + се очаква операнд (израз). Последователността 5 + ; не може да бъде изведена като валиден израз според граматиката.
