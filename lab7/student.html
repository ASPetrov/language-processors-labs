Лабораторно 7

Граматика на STUDENT

Правила за програма, функции, оператори и изрази.

Основни конструкции

Правило (2): тяло на програмата

program_body :
  ( variable_definition SEMICOLON | function_definition )*
  main_function

Нулев или произволен брой глобални дефиниции предхождат задължителната main_function.

Правило (15): извикване на функция

function_call : AT IDENTIFIER LPAREN ( actual_parameters )? RPAREN

Знакът @ е задължителен, а аргументите могат да липсват.

Пример 5: сума на две числа

program {
    suma(int a, int b) -> int {
        return a + b;
    }
    main() -> void {
        print("Suma = ", @suma(10, 5));
    }
}

Формалните параметри са int a, int b, а актуалните аргументи са 10, 5.
