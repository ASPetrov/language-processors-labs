Синтактично дърво

Йерархично представяне на извеждането.

Вътрешните възли представят нетерминали, а листата — терминали. За разлика от линейното извеждане дървото показва вложеността на конструкциите.

Пълно синтактично дърво — пример 6, „Hello, world!“

Дървото следва продукциите от пример 4 и граматиката на STUDENT. Всеки терминал е отделно листо; CHAR_LITERAL представлява съдържанието на низовата константа. Изборите при * са: нула допълнителни дефиниции, един оператор в блока и нула допълнителни аргументи за print.

    • program PROGRAM
    • { LBRACKET
        • main main
        • ( LPAREN
        • ) RPAREN
        • -> ARROW
        • void VOID
          • { LBRACKET
                • print PRINT
                • ( LPAREN
                    • " DOUBLE_QUOTES
                    • Hello, world! CHAR_LITERAL
                    • " DOUBLE_QUOTES
                • ) RPAREN
            • ; SEMICOLON
          • } RBRACKET
    • } RBRACKET

Избери нетерминал, за да видиш граматичното му правило.

Забележка: CHAR_LITERAL е показан като един терминален токен, както в граматиката (правило 25), а не като отделни символи.
