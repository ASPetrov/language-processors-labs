Лабораторно 10

Пример 2 — цикъл while

Разгледайте дървото и връзките между възлите.

Покажи краткия входен код (STUDENT) 
program {
  int i = 1;
  main() -> void {
    while (i < 11) {
      print(i);
      i = i + 1;
    }
  }
}

Дърво на програмата

Изберете възел, за да видите ролята му.

Какво виждаме?

Цикълът while има условие less (i < 11) и блок с print и assignment. При увеличаването на i се използва addition.
