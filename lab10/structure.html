Лабораторно 10

Структура и видове възли

Абстрактното синтактично дърво се представя чрез възли с обща структура и специализирани видове за отделните програмни конструкции.

AST

Възелът може да има свързана лексема, деца и възможност за добавяне на наследници.

Visitable

Позволява посещаване на възли чрез Visitor.

ASTNode

Обща базова реализация за видовете възли.

TypeNode

Тип на данните; PrimitiveTypeNode и VoidTypeNode.

StatementNode

Група възли за оператори.

AssignableNode

Базов клас за възли, които могат да участват в присвояване според описанието .

Понятия, които трябва да разпознавате

program variable definition assignment function block while print

Това са названия на възли, които се виждат в XML примерите. Не бива да ги смесваме автоматично с точните имена на Java класовете в проекта.
