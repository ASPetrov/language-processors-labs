Лабораторно 10

Пример 1 — променлива и main

Разгледайте дървото и връзките между възлите.

Покажи краткия входен код (STUDENT) 
program {
  int i = 10;
  main() -> void {
    print(i);
  }
}

Дърво на програмата

Изберете възел, за да видите ролята му.

Какво виждаме?

Глобална дефиниция на променлива от тип int, присвояване на 10, функция main с резултат void и print с актуален параметър i.
