Отвори src/parser/ParserImpl.java и grammar/ParserGrammar.txt в студентския IntelliJ проект. По-долу са примери от действителния код, не отделен примерен компилатор.

1. Терминални символи — accept()

При съвпадение с очаквания тип лексема се прочита следващата. При несъвпадение се хвърля SyntaxException.

private void accept(TokenType tokenType) {
        if (currentToken.getTokenType() != tokenType) {
            throw new SyntaxException("Token doesn't match! Expected " +
                    tokenType.value + ", Got " + currentToken.getTokenType().value, currentToken);
        }
        currentToken = lexer.nextToken();
    }

2. Стартов символ — entryRule()

Граматично правило 1:

program : PROGRAM LBRACKET program_body RBRACKET
public AST entryRule() {
        accept(TokenType.PROGRAM);
        accept(TokenType.LBRACKET);
        programBody();
        accept(TokenType.RBRACKET);
        return currentNode;
    }

Терминалите се обработват с accept(), а нетерминалът program_body — с извикване на programBody().

3. Цикъл while — правило 20

while_statement : WHILE LPAREN expression RPAREN block

В студентския файл методът whileStatement() съдържа ToDo маркери. Сравни последователността на символите в граматичното правило с местата за извиквания в метода.

void whileStatement() {
        Token token = currentToken;
        accept(TokenType.WHILE);
        accept(TokenType.LPAREN);
        expression();
        ExpressionNode expressionNode = (ExpressionNode) currentNode;
        accept(TokenType.RPAREN);
        block();
        BlockNode blockNode = (BlockNode) currentNode;
        currentNode = new WhileStatementNode(token, expressionNode, blockNode);
    }

4. Избор на правило — statement()

statement : simple_statement SEMICOLON | compound_statement

При рекурсивното спускане изборът се прави по текущата лексема. В студентския код проверката използва isCompoundStatementTerminal(); ако е съставен оператор, се избира съответният метод, иначе — прост оператор, следван от точка и запетая.

void statement() {
        if (TokenType.isCompoundStatementTerminal(currentToken.getTokenType())) {
            compoundStatement();
        } else {
            simpleStatement();
            accept(TokenType.SEMICOLON);
        }
    }
