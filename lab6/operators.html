Оператори и разделители

Алгоритъмът на nextToken() и разпознаването на едно- и двусимволни лексеми.

6.3. Основен алгоритъм

nextToken() взема текущия символ, реда и позицията от Source, пропуска интервали и табулации и избира обработка според първия символ на лексемата.

public Token<TokenType> nextToken() {
    currentChar = source.getCurrentChar();
    line = source.getLineNumber();
    position = source.getPosition() + 1;
    while (currentChar != Source.EOF) {
        switch (currentChar) {
            case ' ': case '\t': handleSpaceAndTabs(); continue;
            case '-': return handleTwoCharOp('>', TokenType.MINUS, TokenType.ARROW);
            case '=': /* ToDo: = и == */
            case '>': /* ToDo: > и >= */
            case '<': /* ToDo: < и <= */
            case '!': /* ToDo: ! и != */
            case '&': /* ToDo: && или OTHER */
            case '|': /* ToDo: | или OTHER */
            case '/': return handleSlash();
            case '\'': return handleCharLiteral();
            case '"': return handleStringLiteral();
            case '+': return retTokenAndAdvance(TokenType.PLUS);
            // ToDo: [, ], {, }, (, ), ;, *, %, ,, @
            default:
                if (isLetter(currentChar)) return handleIdentifier();
                if (isDigit(currentChar)) return handleDigit();
                return retTokenAndAdvance(TokenType.OTHER, currentChar + "");
        }
    }
    return null;
}

Коментарът ToDo е част от домашната задачата.

6.3.1. Едносимволни оператори и разделители

case '+': return retTokenAndAdvance(TokenType.PLUS);

Един символ е достатъчен за определяне на типа. В задачата трябва да се добавят и останалите едносимволни оператори и разделители.

6.3.2. Двусимволни оператори и разделители

case '-': return handleTwoCharOp('>', TokenType.MINUS, TokenType.ARROW);

При - следващият символ определя дали резултатът е MINUS, или ARROW. Аналогично се разграничават = и ==, > и >=, < и <=, ! , != и &&, ||.
