Лексеми и структура

Интерфейсът Token, изброимият тип TokenType и файловете на лексическия анализатор.

6.1. Дефиниране на лексеми

Класът Source предварително премахва символите за нов ред и подава програмата като символен низ. Лексическият анализатор извлича лексемите от този поток.

public interface Token<Type> {
    public Type getTokenType();
    public String getText();
    public int getPosition();
    public int getLine();
}

Всяка лексема предоставя тип, текст, позиция и ред. Вътрешните имена и символните стойности са дефинирани в TokenType.java. Примерни дефиниции:

INT("int"), CHAR("char"), BOOLEAN("boolean"), VOID("void"),
WHILE("while"), IF("if"), ELSE("else"), RETURN("return"),
LENGTH("length"), PROGRAM("program"), PRINT("print"),
READ("read"), TRUE("true"), FALSE("false")

6.5. Файлова структура

Къде се намира реализацията?

  • lexer/LexerImpl.java — алгоритъм на лексическия анализ.
  • token/TokenImpl.java — реализация на лексема.
  • token/TokenType.java — дефиниции и разпознаване на типовете лексеми.

Провери разбирането

Кой метод от Token връща позицията на лексемата?

getPosition(). getLine() връща реда, а getText() — текста.
