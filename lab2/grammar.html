Формална граматика

Граматиката задава символите и правилата, чрез които могат да се построят думите на езика.

G = (N, T, P, S)

Формалната граматика се задава чрез четири компонента.

КомпонентЗначение
Nмножество от нетерминални символи
Tмножество от терминални символи
Pмножество от продукционни правила
Sначален символ, S ∈ N
Терминалите остават в крайния резултат. Нетерминалите са помощни символи, които се заменят чрез правилата.

Минимален пример

S → aS
S → b

Тук N = {S}, T = {a,b}, началният символ е S, а P съдържа двете показани правила.

Провери се: В правилото S → aS кои символи са терминални?
a е терминал. S е нетерминал.

Пример, близък до програмен език

program → PROGRAM { body }
body    → main
main    → MAIN ( ) → VOID block

Тук граматиката вече описва структура на програма. По-късно синтактичният анализатор ще използва подобни правила, за да провери дали входната програма има допустима структура.
