Упражнения в лабораторията

Тези задачи се решават в часа. Те преминават от разпознаване на елементите на граматиката към извеждане и класификация.

Задача 1 — Компоненти на граматиката

S → aA
A → bA
A → b

Определи N, T, P и S.

N = {S, A}; T = {a, b}; S е началният символ; P са трите продукционни правила.

Задача 2 — Извеждане

S → aS
S → b

Изведи думата aaaab стъпка по стъпка.

S ⇒ aS ⇒ aaS ⇒ aaaS ⇒ aaaaS ⇒ aaaab

Задача 3 — Принадлежност към езика

S → 0S
S → 1

Кои от думите 1, 001, 0101, 0001 принадлежат на езика?

1, 001 и 0001. Думата 0101 не може да бъде изведена.

Задача 4 — Класификация

S → aA
A → bS
A → b

Към кой тип от йерархията на Хомски принадлежи граматиката? Обоснови отговора чрез формата на правилата.

Граматиката е регулярна (тип 3): правилата са дясно-линейни — терминал, евентуално последван от един нетерминал.

Задача 5 — Извеждане на програмна конструкция

program → PROGRAM { body }
body    → main
main    → MAIN ( ) → VOID block
block   → { }

Започни от program и получи крайната програмна конструкция, като записваш всяка междинна стъпка.

program ⇒ PROGRAM { body } ⇒ PROGRAM { main } ⇒ PROGRAM { MAIN ( ) → VOID block } ⇒ PROGRAM { MAIN ( ) → VOID { } }
