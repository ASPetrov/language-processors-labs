Функции и рекурсия

Функциите приемат параметри и могат да връщат резултат чрез return.

Функция за по-голямото число

program {
    greater(int num1, int num2) -> int {
        if (num1 > num2) { 
            return num1;
        }
        else {
            return num2;
        }
    }
    main() -> void {
        print(@greater(10, 5));
    }
}

Формалните параметри са num1 и num2; при извикването се подават актуални аргументи.

Функция за сума

program {
  suma(int a, int b) -> int {
      return a + b;
  }
  main() -> void {
    print("Suma = ", @suma(10, 5));
  }
}

Знакът @ е задължителен при извикване на функция.

Рекурсия: функция може да извиква себе си. В домашна задача 2 ще приложиш това за факториел.
