Лабораторно 4

Едномерни масиви

Масивът съхранява последователност от стойности от един и същи тип.

Деклариране и достъп

int[] arr = int[10];
arr[0] = 1;
arr[1] = 2;

Индексите за масив от 10 елемента са от 0 до 9.

Пълна програма с масив


program {
  main() -> void {
    int[] arr = int[10];
    arr[0] = 1;
    arr[1] = 2;
    arr[2] = 3;
    arr[3] = 4;
    arr[4] = 5;
    arr[5] = 6;
    arr[6] = 7;
    arr[7] = 8;
    arr[8] = 9;
    arr[9] = 10;

    int i = 0;
    while (i <= 9) {
      print(arr[i]);
      print(" ");
      i = i + 1;
    }
  }
}

Пример 5 от ръководството: обхождане и извеждане на елементите.

За обхождане на масив използвай while и индекс, който се увеличава при всяка итерация.
