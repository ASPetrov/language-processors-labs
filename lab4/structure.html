Лабораторно 4

Структура на STUDENT

STUDENT е процедурно-ориентиран учебен език, използван за разработването и тестването на компилатор.

Ограничения

Няма обектно-ориентирано програмиране. Поддържа три прости типа данни, едномерни масиви и подпрограми функции.

Минимална програма

program {
  main() -> void {
    print("Hello, world!");
  }
}

Програмата започва с program и съдържа функция main().

Важно: Дефиницията на функция използва -> пред типа на резултата. main() -> void не връща стойност.
