Азбука и ключови думи

Символите и запазените думи са основата на лексиката на езика.

Азбука

Латински букви a–z и A–Z, цифри 0–9 и специални символи, включително + - * / % ; ( ) [ ] { } @ & | ! > < = и кавички.

14 ключови думи

if  int  char  else  read  true  void
false  while  print  length  return  boolean  program

length се използва за броя на елементите в масив, read за вход, print за изход.

Идентификатори

Започват с буква, последвана от букви или цифри. Например number1 е допустим, а 1number — не.

Допустим ли е идентификаторът total2?
Да — започва с буква и съдържа само букви и цифри.
