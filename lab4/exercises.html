Упражнения в лабораторията

Решаваме задачи 1, 3 и 4 от ръководството. Решенията са скрити, за да опиташ самостоятелно.

Задача 1

1. Да се напише програма на STUDENT, която извежда сумата на целите числа от 1 до 10. 

program {
  main() -> void {
    int sum = 0;
    int i = 1;
    while (i <= 10) {
      sum = sum + i;
      i = i + 1;
    }
    print(sum);
  }
}

Задача 3

3. Да се напише програма на STUDENT, която извежда стойността на факториел за число, подадено като параметър на функция, като се използва итеративен алгоритъм. 

program {
  factorial(int n) -> int {
    int result = 1;
    int i = 1;
    while (i <= n) {
      result = result * i;
      i = i + 1;
    }
    return result;
  }
  main() -> void {
    print(@factorial(5));
  }
}

Задача 4

4. Да се напише програма на STUDENT, която изчислява и извежда сумата на числата в масив от 10 цели числа. 

program {
  main() -> void {
    int[] arr = int[10];
    int i = 0;
    int sum = 0;
    while (i < 10) {
      read(arr[i]);
      sum = sum + arr[i];
      i = i + 1;
    }
    print(sum);
  }
}
