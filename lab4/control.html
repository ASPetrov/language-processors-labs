Лабораторно 4

Управляващи конструкции и вход/изход

Условен оператор

if / else

if (a > b) {
    print(a);
} else {
    print(b);
}

Цикъл while

Повторение

int i = 0;
while (i < 5) {
    print(i);
    i = i + 1;
}

read и print

Проверка на число в диапазона 0–9

program {
  main() -> void {
    int a = -1;     
    read(a);	
    while ( (a < 0) || (a > 9) ) {
      print("Enter a number in the range 0-9: ");
      print("\n");
      read(a);
    }
    print("a = ", a); 
    print("\n");
  }
}

Програмата повтаря въвеждането, докато числото не попадне в допустимия диапазон.

В STUDENT няма оператор for. За повторения се използва while.
